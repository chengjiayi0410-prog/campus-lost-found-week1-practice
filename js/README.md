# 校园失物招领

一个使用 HTML、CSS、JavaScript 编写的校园失物招领静态原型。

项目用于练习页面结构、响应式布局、DOM 渲染和组合筛选。

## 功能

- 12 条失物与招领演示数据
- 关键词搜索
- 按失物/招领筛选
- 按物品分类筛选
- 类型和分类组合筛选
- 无结果提示
- 清除筛选
- 信息详情弹窗
- 手机端响应式布局

## 技术栈

- HTML5
- CSS3
- 原生 JavaScript
- Git

## 本地运行

直接用浏览器打开 `index.html`。

不需要安装依赖，也不需要启动后端服务。

## 项目结构

```text
week1/
├── index.html          # 页面结构
├── css/
│   └── style.css       # 页面样式和响应式布局
└── js/
    └── app.js          # 演示数据、筛选、渲染和弹窗
```

## 学习重点

- 使用语义化 HTML 组织页面结构
- 使用 Flex 和 Grid 完成页面布局
- 使用数组 `filter` 实现多条件筛选
- 使用 `<template>` 和 DOM API 动态渲染列表
- 使用原生 `<dialog>` 实现详情弹窗
- 使用媒体查询完成移动端适配
- 使用 Git 记录开发过程

## 当前限制

- 数据保存在 `js/app.js` 中，没有连接数据库。
- “发布”按钮暂时只是界面占位。
- 刷新页面后会恢复为初始的 12 条演示数据。
